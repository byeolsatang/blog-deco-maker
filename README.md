# blog-deco-maker
ブログ記事を見やすく装飾するためのツール。

アメブロはモバイル表示で`<style>`が効かないため、スタイルを直書きしたタグを作り、HTML編集画面に貼り付けて使います。

## 作れる装飾
- **囲み**：背景だけ／背景＋枠線／点線枠／二重線／まる枠／左ライン／上ライン／ステッチ／ずらし影／見出し帯（タイトル付きも可）
- **引用**：左ライン／線だけ／“ ”マーク（出典付きも可）
- **コード**：文中（インライン）／ブロック（複数行）
- **マーカー**：下半分マーカー／全体マーカー／太めの下線／波線／文字色＋太字
- **見出し**：左ライン／下線／背景帯／左ライン＋下線／ラベル／中央・上下線
- **ボタン**：塗り／枠線／うす塗り
- **区切り線**：実線／破線／点線／二重線／飾り

カラーはピンク・パープル・ブルー・ミント・イエロー・オレンジ・グレーの7色です。

## 使い方
1. 種類を選んでテキストを入力
2. スタイルと色を選ぶ
3. 「タグをコピー」を押す
4. アメブロの「HTML表示」に切り替えて貼り付け

## アプリとして使う（PWA）
- **iPhone**：Safariで開いて、共有ボタン →「ホーム画面に追加」
- **Android**：Chromeで開くと右上に「アプリを追加」ボタンが出ます

一度開けば、オフラインでも使えます。

### 更新するとき
`sw.js` の `VERSION`（例：`"v1"` → `"v2"`）を上げてからプッシュしてください。次に開いたとき、利用者の画面に「更新」ボタンが表示されます。
